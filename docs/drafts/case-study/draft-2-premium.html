Calls I made, and why.

Sign-in codes go over WhatsApp, not SMS.

Meta's Cloud API costs about ₹0.14 a message with no reseller in between. SMS verification runs near ₹6, and Indian carriers often bury or block it.

≈ 40× cheaper per sign-in

Commission is set per order, and partners never see it.

The admin can test rates without renegotiating or redeploying. Partners see only the cash they collected and what they keep, so a changing percentage never causes friction.

Taking cash is a confirmation, not a form.

The partner taps "Got ₹410 cash" instead of typing an amount. Fewer taps, no typos, and the amount always matches the order.

Delivery shows as FREE instead of disappearing.

Every order already stores a delivery charge of zero. Charging later is a data change, not a redesign, and customers read the line as a perk today.
